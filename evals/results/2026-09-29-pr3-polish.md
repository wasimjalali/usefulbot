# PR 3 UX polish: live verification (2026-09-28/29)

## Question

Does each fix in the PR 3 polish pass hold in the running macOS app, including anything that
moves? Every check ran against a `npm run build:app` bundle of `feat/pr3-polish`, driven in the
background with cua-driver and recorded with `winrec` at 30 or 60 fps. Frame sheets are in
`2026-09-29-pr3-polish/`.

## What ran

- App: `macos/dist/Useful Bot.app` built from the branch, Apple M1, macOS 26.6.2.
- Live turns: Test Bot only, header pill checked by screenshot before every send. Model
  GPT-6-Luna, Medium. Cost: a handful of short turns on existing subscriptions.
- A clean first run: services started by hand with `HOME` pointed at an empty folder holding
  only a copy of `~/.useful-bot/config.json` (so the Keychain token digests still matched) and
  a symlink to `~/Library/Keychains`. `setup-local.mjs` was not run: it would have re-minted
  the real install's Keychain tokens.

## Conclusion and what changed

All listed fixes hold in the running app. The chat-open item carried over from #145 was
measured, not fixed: warm switches swap in one frame, and the slow case is the first open after
a rebuild or an update. Keying snapshots to the build is what makes every update pay a full
replay per chat, which is worth its own look before launch.
